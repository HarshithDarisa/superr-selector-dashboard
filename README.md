# SupeRR Selector dashboard

1. Create a GitHub repository and upload all files in this folder.
2. Open https://share.streamlit.io/ and connect the repository.
3. Select `app.py` as the main file.
4. Deploy. The app reads only the two compact audited leaderboard CSVs.
5. Share the Streamlit Community Cloud URL after testing it in an incognito window.

The app is a public demonstration dashboard. Do not upload private credentials or tokens.
